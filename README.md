# SignSpeak-AI
SignSpeak AI adalah aplikasi berbasis kecerdasan buatan (AI) yang membantu penyandang tuli memahami percakapan secara real-time. Aplikasi mengubah suara menjadi teks, memahami konteks percakapan menggunakan AI, kemudian menerjemahkannya ke dalam bahasa isyarat melalui animasi atau avatar digital.
